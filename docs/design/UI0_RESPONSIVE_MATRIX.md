# UI-0 · 多设备响应式矩阵

> 依据：现状 `Index.ets`（`isTablet = width >= 600`、584/629 行两处分叉）、`PlannerPage`/`ReversePage`
> 单栏布局；真机仅验证 **MIA-AL00 直板**（其余设备 **NOT_RUN**）。
> 本文件是设计约束与验证计划，不代表已实现。

## 1. 断点定义（按窗口可用空间，不按设备名）

| 类别 | 可用宽度 | 典型形态 | 导航 | 内容栏 |
|---|---|---|---|---|
| Compact | < 600vp | 手机直板、折叠外屏 | 底部 5 Tab | 单栏 |
| Medium | 600–839vp | 折叠展开、小平板竖屏 | 侧边 88vp 图标栏 | 单栏（最大内容宽 720） |
| Expanded | 840–1199vp | 平板横屏、双折叠展开 | 侧边 240vp 文字栏 | 主 + 侧 2 栏（主从） |
| Large | ≥ 1200vp | 三折叠全展开、2-in-1、自由窗口 | 侧边 240vp | 3 栏（导航 + 主 + 检查器） |

关键规则：

1. **以窗口实际宽度/高度计算**，不用 `deviceType` 分支；折叠/分屏/自由窗口缩放必须实时重算；
2. 高度约束优先于宽度：可用高度 < 560vp 时，hero 卡与大标题降级（收紧 padding、隐去副标题）；
3. 折痕/铰链：跨折痕的图表与滑块禁止跨越；若形态为分屏（如折叠内屏半屏），
   主内容与检查器分置两侧；
4. 安全区：底部 Tab 与手势条偏移 ≥ `safeArea.bottom`；顶部避让状态栏与挖孔；
5. 编辑态保护：`PlannerPage` 编辑中若窗口类别变化，**保留表单状态**、不重建组件树，
   仅在布局层面重排（禁止因旋转丢失 `pickedDate/selectedUtc/清单`）。

## 2. 页面适配矩阵

| 页面 | Compact | Medium | Expanded | Large | 说明 |
|---|---|---|---|---|---|
| home | 单栏 | 单栏 + 更大曲线 | 左：hero+KPI / 右：曲线+时段 | 3 栏（导航/主/今日摘要） | 曲线在宽屏必须占 ≥40% 宽 |
| sunpath | 曲线 + 滑块纵排 | 曲线 60% + 控件 40% | 曲线左、控件右常驻 | 同 Expanded + 侧栏图例 | 折痕处断开 |
| reverse | 表单 → 结果纵排 | 表单折叠为摘要 + 结果 | **主从**：左表单 360vp / 右结果 | 3 栏 + 结果详情 | 结果卡宽 ≥320 才并排 |
| locations | 列表 | 列表 + 详情抽屉 | 主从（列表 + 详情） | 3 栏 | 删除需二次确认 |
| compass | 单栏大方盘 | 方盘 + 数值侧列 | 方盘 + 侧栏读数 | 同 Expanded | 保持 1:1 方形容器 |
| map | 全屏地图 + 底部抽屉 | 地图 + 右侧抽屉 | 主从 | 3 栏 | 定位失败降级手动输入 |
| planner | 分区纵排 | 两栏（时间/机位） | 主从（表单 + 清单） | 3 栏 | 编辑态保护（见上） |
| calendar | 月历单栏 | 月历 + 当日摘要 | 月历左、摘要右 | 月历 + 摘要 + 计划列表 | 单元格最小 44×44 |
| compare | 纵排对照 | 两列并排 | 多列 + 曲线 | 多列 + 曲线 + 图例 | 列数上限 4，超出横向滚动 |
| settings | 单栏分组 | 单栏（最大宽 640） | 左分类 + 右内容 | 3 栏 | — |
| Index 壳 | 底部 Tab | 图标侧栏 | 文字侧栏 | 3 栏 | 导航状态需随窗口保持 |

## 3. 图表与媒体比例

| 组件 | Compact | Medium | Expanded+ |
|---|---|---|---|
| 太阳高度曲线 | 高 ≥180vp，宽铺满 | 高 ≥220 | 高 ≥260，宽 ≥40% |
| 时间轴 | 横向滚动，刻度 ≥6 个 | 刻度 ≥8 | 全量刻度 + DST 标记 |
| 罗盘 | 宽高 1:1，取 min(宽, 高×0.5) | 同 | 固定 ≤360vp |
| 地图 | 高 ≥ 55% 屏高 | 60% | 主从时 ≥70% |

## 4. API 26 设备条件核对（状态：NOT_RUN）

| 形态 | 需要的验证 | 状态 |
|---|---|---|
| 直板手机 | 已用 MIA-AL00 验证基础布局 | **DEVICE_PASS（仅直板）** |
| 折叠外屏/内屏 | 实际窗口尺寸、折痕区域、切换时状态保持 | **NOT_RUN**（无设备） |
| 双/三折叠展开 | 大屏多栏、状态栏避让、重排实时性 | **NOT_RUN** |
| 平板横竖屏 | Medium/Expanded 断点、横竖切换 | **NOT_RUN** |
| 2-in-1/自由窗口 | 任意宽高比、拖拽缩放、最小窗口 | **NOT_RUN** |

> 设计稿与矩阵只能用真机验证；不得把设计模拟当成真机兼容性结论。

## 5. 实施顺序建议

1. 抽出 `WindowClass` 工具（compact/medium/expanded/large）替换 `isTablet`；
2. 先做 reverse（主从）与 planner（分区）两页，验证编辑态保护；
3. 再做 calendar/compare 多列；
4. 最后做 3 栏与 2-in-1（依赖真机）。
