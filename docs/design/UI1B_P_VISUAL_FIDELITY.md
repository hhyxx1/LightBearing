## 3. 真实图表与视觉插值说明

- 曲线采样自 `sampleRange(tm.startUtc, tm.endUtc, lat, lon, 10)`，x 轴由 `Timeline.fromBounds` 的**真实本地日**映射，非 24 小时兜底；
- `Timeline` 无效时只画「当日时间轴不可用」，不画假曲线；
- 时段带取真实窗口 UTC 对，并按 `[dayStart, dayEnd)` 裁剪；窗口不可用（极昼/极夜/无穿越）时**不画**；
- 视觉上仅做颜色与透明度处理，未改变任何可查询的物理数值（`SolarCalc.position` 结果不被插值覆盖）；
- 太阳标记与读数使用同一 `selectedUtc`，不存在「标记在 A、读数在 B」。

## 4. 断点与导航壳关系

```text
窗口宽度 → Index（>=600 显示 212vp 导航）→ 发布 lbContentWidth = 窗口 − 导航
HomePage 读取 lbContentWidth：
  < 600    → 单列（Compact）
  >= 600   → 双栏（面板 + 时段/计划）
  >= 1200  → 三区（中央观测 + 320vp 检查器）
```

- 未出现两套断点冲突；`selectedUtc / sliderProgress` 只由用户操作改变，窗口变化仅重算档位；
- 已检查阈值附近：599/600（导航出现）、839/840/1199/1200（内容宽度）；**未做**真实折叠/平板设备验证。

## 8. 剩余问题

1. Expanded/Large 仍为「单列面板 + 侧栏」，未实现原型中「大画布主工作区」的比例；
2. 曲线为 10 分钟采样折线，视觉上偏「三角形」，未做平滑（按约束不做会改变数值的插值美化）；
3. 迷你日轨弧线未做（判定与现有曲线重复）；
4. 时段带在 24h 轴上仅约 3% 宽度，视觉辨识度有限（真实窗口就是这么短，未放大造假）；
5. 空机位 / 权限拒绝态截图仍为 NOT_RUN（需改数据或权限，约束不允许）。
