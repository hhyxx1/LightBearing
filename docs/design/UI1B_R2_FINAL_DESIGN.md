# UI-1B-R2 · 专业摄影工作台最终视觉方案

> 基准 `3727237` → 本轮提交见汇报。分支 `fix/core-quality-audit`，**未修改任何生产代码**
> （HomePage / ObservationPanel / Charts / SolarCalc / AppDb 均未动），`ObservationBands` 的负时间戳修复保留。
> 本轮只交付设计原型 + 可复现 fixture + 评估证据，等待用户选定后才进入生产实现。

## 1. 最终信息架构

方向：**A · Precision Instrument 为主体 + B · 全天分段带 + C · 下一窗口提示**（不是三张页面拼接）。

```text
紧凑上下文（1 行）  机位名 · 日期 周四 · 时区偏移 · 场景切换 · 主题切换
仪表（主视觉）      方位角（琥珀）/ 高度角（青）/ 光线阶段 + 选中时刻与 UTC 偏移
观测曲线            真实采样折线 + 地平线 + 高度刻度 + 当前太阳标记 + 黄金/蓝调铺底
全天分段带          夜间/天文/航海/蓝调/黄金/白昼，按真实比例；图例 + 时间轴刻度
下一窗口（单处）    当前处于目标时段 → 「当前处于X时段 · 预计 HH:mm 结束 · 剩余约 N 分钟」
                    否则 → 「下一可拍：X HH:mm–HH:mm」，点击定位到该时刻
明细（折叠）        计算出的黄金/蓝调窗口列表
操作                反向寻光（主）/ 完整日轨 / 机位·计划
底部导航            今日 · 轨迹 · 计划 · 设置 · 更多（语义化线性图标，选中琥珀 + 下划线）
```

**去重规则**：日出日落只在明细里出现一次；「下一窗口」只占一处；阶段只在仪表内出现一次。

## 3. 颜色 / 字级 / 动效

- 颜色：`--bg #0B1622`、`--surface #152836`、`--surface-2 #1C3546`、`--amber #FFBC6B`、`--cyan #73D9D5`、
  `--ink #F9FAF3`、`--muted #93A9B6`；浅色为暖纸基底（`#F4F1EA / #FFFFFF / #9A5A0C / #116C69`）。
- 字级：显示 34 / 标题 17–19 / 正文 12–14 / 说明 10.5–11.5；数值统一 `tabular-nums`。
- 动效：仅 CSS 过渡（120ms 级）+ 详情箭头旋转 + 高亮切换；`body.reduce` 下全部关闭；
  **动画不触碰** `selUtc`、分段或任何窗口数据。

## 4. 数据来源与日期一致性

`tools/ui1b-r2/gen-fixtures.js` 生成 `design/ui1b-r2/fixtures/fixtures.js`
（与 SolarCalc 同一 NOAA/Meeus 公式族的镜像，5 分钟采样；**设计 fixture，不是运行时数据**）：

| fixture | 内容 | 当日长度 | 关键值 |
|---|---|---|---|
| `shanghaiGolden` | 上海 2026-11-05，黄金时段进行中 | 24h | now alt 1.7° / az 109.4° |
| `shanghaiNight` | 上海 同一日 03:30 本地 | 24h | alt −35.1° |
| `tromsoDay` | 特罗姆瑟 2026-06-21 极昼 | 24h | 全天仅 3 段（白昼为主） |
| `tromsoNight` | 特罗姆瑟 2026-12-22 极夜 | 24h | 9 段，无白昼 |
| `nyDst` | 纽约 2026-11-01 回拨日 | **25h** | 时间轴按 25h 映射 |
| `shanghai1969` | 上海 1969-12-31（负时间戳） | 24h | 正常出图，负值不丢窗口 |

一致性约束：日期与星期取自真实日历（**2026-11-05 为周四**，已修正上一轮错误）；
同界面只有一个 UTC 偏移；分段边界由同一批采样按产品阈值（>6 白昼 / −4..6 黄金 / −6..−4 蓝调 /
−12..−6 航海 / −18..−12 天文 / <−18 夜间）生成，与曲线同源，不存在「曲线与色带不一致」。

## 6. 可交互能力（don't fake）

| 交互 | 实现 |
|---|---|
| 拖动曲线选择时刻 | pointerdown/move → 按 x 比例映射到 UTC → 最近样本 |
| 标记与读数同步 | 标记、方位、高度、时刻、偏移、阶段由同一 `selUtc` 推导 |
| 场景切换 | 下拉切换 6 组 fixture（含极昼/极夜/DST/1969） |
| 点击下一窗口 | 定位到该窗口起点（无窗口时该行显示「该日无可用可拍时段」，点击无效） |
| 详情折叠 | 「光线时段明细」展开/收起 |
| 底部导航 | 选中态琥珀 + 下划线（仅视觉，无路由实现） |
| 深浅色 | 顶栏按钮切换（仅视觉） |
| 减少动效 | `?reduce=1` 或 `body.reduce`，所有过渡关闭 |

**未伪装**：没有「设提醒」「分享」等未实现功能；主按钮只标「反向寻光/完整日轨/机位·计划」。
文案保持客观：不写「适合拍摄」，只写「当前处于黄金时段」「预计 HH:mm 结束」。

## 7. 与旧 UI-1B-P 真机截图的区别

| 维度 | UI-1B-P（`ui1b_p_after_home_dark.jpeg`） | 本轮方案 |
|---|---|---|
| 首屏 | 大标题 + 机位 + 大数字 + 曲线，关键时段需下滑 | 上下文压缩为 1–2 行，仪表 + 曲线 + 分段带 + 下一窗口同屏 |
| 时段表达 | 曲线内两根细竖条 | 曲线内铺底 + **全天分段带（真实比例 + 图例）** |
| 下一窗口 | 无（只有时段明细） | 单处「当前/下一窗口」+ 剩余分钟 + 点击定位 |
| 曲线 | 10 分钟采样折线，刻度少 | 5 分钟真实采样 + 20° 刻度 + 0° 地平线 + 图例 |
| 重复信息 | 阶段徽标重复出现 | 阶段只在仪表出现一次 |
| 图标 | 空心方框占位 | 语义化线性图标（太阳/日轨/日历/设置/更多） |

## 8. 仍存在的不足

1. 分段带中极短窗口（如蓝调 10–20 分钟）在 24h 比例下仍很窄，仅靠图例与「下一窗口」补偿，尚无局部放大视图；
2. 曲线未做平滑（按约束不做会改变数值的插值美化），视觉上仍是折线；
3. Expanded/Large 只有渲染预览，未在折叠/平板/2-in-1 真机验证；
4. 键鼠、设备接续、多窗口拖动等尚未设计交互细节；
5. 3 套旧概念（A/B/C）仍保留在 `design/ui1b-r/`，未删除，便于复审对比。
