# UI-0 · 动效规范（Motion Design）

> 本文件是规范与实现约束，**本轮未改动任何动效代码**（实现落在 UI-1）。
> 现状核查：页面里存在零散隐式动画/过渡，但没有统一的时长、曲线与「减少动态效果」处理。

## 1. 时长与曲线

| 场景 | 时长 | 曲线 | 说明 |
|---|---|---|---|
| 小控件反馈（按钮/chip 按下） | 90–120ms | ease-out | 只改透明度/缩放 ≤0.98 |
| 卡片展开/收起（共享元素） | 200–240ms | ease-in-out | 与 Navigation 的 sharedTransition 配合 |
| 页面进入 / 返回 | 240–280ms | ArkUI 默认转场曲线 | 使用 Navigation 原生转场，不自绘 |
| Tab 切换 | 160–200ms | ease-out | 内容淡入 + 位移 ≤8vp；禁止整页横移 |
| 底部弹层（ProgressSheet） | 220–260ms | ease-out 进入 / ease-in 退出 | 遮罩同步淡入 |
| 搜索进度 | 120ms 步进 | linear | 仅进度条/百分比，数字不得跳变 |
| 搜索结果显示 | 180ms 淡入 + 8vp 上移 | ease-out | 结果逐条错开 ≤30ms，超过 6 条不再错开 |
| 时间轴/太阳轨迹插值 | 100–160ms | linear | 拖动时跟随手指，松手后吸附 |
| 折叠展开 / 窗口缩放 | 由系统驱动 | 系统曲线 | 应用只做布局重排，不加自定义动画 |
| 跨设备接续反馈 | 200ms 高亮相框 | ease-out | 仅在真实接续成功后出现 |

统一常量（UI-1 落地）：`motion.fast=120 / base=200 / slow=280`，曲线只允许
`easeOut / easeInOut / linear` 三种，禁止每个页面自定义贝塞尔。

## 2. 硬性约束（不得违反）

1. **动效绝不改变业务状态**：日期、`selectedUtc`、搜索进度百分比、编辑中的表单内容，
   只能由用户操作或数据加载改变；动画不得写入这些值，也不得在动画回调里「顺手」修正它们。
2. 进度条动画与实际 `sheetPercent` 解耦：动画目标是已计算值，不允许插值结果被回写到状态。
3. 滑块拖动：手指位置 → 值映射是同步的；吸附动画只影响视觉位置，不影响最终值。
4. 共享元素转场只允许传递「已存在」的数据对象（如窗口的 `bestUtc`），不允许在转场中重算 UTC。

## 3. 可访问性与性能

| 条件 | 处理 |
|---|---|
| 系统「减少动态效果」开启 | 所有非必要动画时长归零（等效 0ms），仅保留 ≤120ms 的透明度变化；Tab/页面切换直接切换 |
| 低性能设备 / 低电量模式 | 关闭共享元素与错开淡入，仅保留 120ms 透明度 |
| 高刷新率（90/120Hz） | 不额外增加动画时长；使用 ArkUI 原生动画（`animateTo` / `Navigation` 转场）以保证帧率 |
| 长列表 | 禁止对整个 `ForEach` 做布局动画，只对新增项淡入 |

## 4. 推荐 API（API 26 可用性需在实现时核实）

- 属性动画：`animateTo({ duration, curve }, () => { ... })`
- 组件转场：`Navigation` + `NavDestination` 原生转场；`sharedTransition(id, options)`
- 手势跟随：`PanGesture` 回调内直接设值（不加动画），松手后再 `animateTo` 吸附
- 减少动态效果：读取系统无障碍设置（具体 API 需实现时核实），不在页面内自造开关

## 5. 验收方式（UI-1）

1. 录屏逐场景比对时长（人工计时表，非伪造）；
2. 自动化检查「减动效开启后无 >120ms 的动画」；
3. 断言动效前后 `selectedUtc/进度/表单值` 不变。

## 6. 状态

规范已定义；**实现与实机验证均为 NOT_RUN**（本轮不改动效代码）。
