# UI-0 · 视觉差异分析（原稿 ↔ 现状）

> 基准 `728b9cf`。原稿存在且已实际读取：`lightbearing_ui.html`（67 行，含 10 个页面定义与
> 设计 token 面板）、`lightbearing_dev_prd.md`（209 行，S01–S10 逐页交互合约）。
> 现状依据：`entry/src/main/ets/pages/*.ets`（13 页）、`common/Theme.ets`、`components/*.ets`、
> 真机截图 `docs/screenshots/`（qa2b_*、qa2c_01_home 已实际查看）。

## 1. 总体结论（先说结论，后给证据）

| 维度 | 原稿 | 现状 | 判定 |
|---|---|---|---|
| 明暗基线 | **深色**：`--bg:#0D1A29`、`--ink:#F9FAF3`、主色 `#FFBC6B`、辅色 `#73D9D5` | 真机截图是**浅色**（米白底 + 深色文字），主色仍为琥珀色系 | **重大差异**（需确认是否双主题并存） |
| 导航结构 | 桌面三栏：256px 侧栏 + 主区 + 292px「DESIGN SYSTEM」栏；≤780px 折叠为顶部横向 tabs | 移动端**底部 5 Tab**（今日/轨迹/计划/设置/更多），无侧栏、无设计系统栏 | 差异（移动优先 vs 桌面优先） |
| 页面数量 | 10 页（home/sunpath/reverse/locations/compass/map/planner/calendar/compare/settings） | 13 页（另加 Index 壳、PlaceDetailPage、PlanDetailPage） | 实现多于原稿：**详情页缺设计依据** |
| 断点 | 1200px、780px 两档 | 单一 `isTablet = width >= 600` | 断点体系需重建 |
| 卡片圆角 | 16vp（正文说明），hero 24vp | `Radius.CARD=19`、`HERO=24`、`BUTTON=12`、`CHIP=40` | 卡片 19 vs 16 不一致 |
| 字级 | 正文 14–16 / 标题 20–36 | BODY 14、BODY_L 15、TITLE 20、H1 30、HERO_H2 22 | 基本对齐，缺 36 档与大标题层级 |
| 网格 | 4 / 8 / 12 / 16 / 24 / 32vp | Spacing 4/8/12/16/20/24/32（多 20） | 基本一致 |
| 触控热区 | ≥44vp | `MIN_TOUCH` 常量（页面统一使用） | 一致（值需一次核对） |
| 动效 | 160–240ms，且 `prefers-reduced-motion` 全关 | 无统一动效规范；组件里有个别隐式动画 | 需正式规范（见 `UI0_MOTION_SPEC.md`） |

## 2. 逐页差异（按 PRD 的 S01–S10 + 实现新增页）

| 页面 | 原稿要素 | 现状 | 差异/问题 | 建议 |
|---|---|---|---|---|
| **S01 home 今日光线** | eyebrow + 大标题 + 副标题 + hero 卡（双按钮）+ 2 列卡片网格 + 三列 KPI + 曲线 | 截图确认：eyebrow/大标题/副标题/hero 卡/三列 KPI/曲线卡，结构一致；配色为浅色 | 配色基线不同；hero 卡文案较长时占三行 | **保留**（结构最成熟）；只做主题与密度校准 |
| **S02 sunpath 太阳轨迹** | 日轨曲线 + 地平线 + 时刻拖动 + 日出日落 + 十字准星画布 | `SunPathPage` + `Charts.SunPathChart` + 滑块 + 罗盘 | 缺原稿的「十字准星 canvas」视觉语言；滑块与曲线联动有，但缺少拖动时的吸附提示 | 保留交互，重做图表视觉与标注层 |
| **S03 reverse 反向寻光** | 参数表单（方位/高度/容差/天数）+ 候选时间与误差 + 状态机 | 表单齐全 + 窗口卡（起止/时长/UTC 偏移）+ 进度浮层 | 结果卡信息密度过高（时间/范围/误差/按钮同屏）；空态/失败态文案刚统一 | **重排结果卡**：一行时间、一行误差、一行范围，按钮下移 |
| **S04 locations 机位库** | 列表 + 输入坐标 + 标签 + 搜索 | 列表 + 新增/编辑/删除 + TEST 机位 | 无常驻搜索框与标签筛选（原稿有） | 补搜索/筛选；列表项密度对齐 4vp 网格 |
| **S05 compass 现场罗盘** | 传感器方位 + 校正 + 太阳参考 + 误差提示 | `CompassPage` + `SensorService` + ±15° 校正 + 15s 定时器 | 无「太阳参考方位」叠加层视觉 | 补叠加层与误差带 |
| **S06 map 地图** | 机位标记 + 方向射线 + 失败降级手动输入 | `MapPage` + 定位授权 + 手动经纬度 | 方向射线未实现；降级路径有 | 射线可视化 + 降级文案统一 |
| **S07 planner 拍摄计划** | 目标机位 + 候选窗口 + 行前清单 + 备注 | 表单 + 清单 + 备注 + GAP/OVERLAP + 机位快照保护 | 表单很长（821 行页面），编辑态缺少分区标题 | **分区重排**：时间 / 机位 / 参数 / 清单 / 备注 |
| **S08 calendar 日历** | 月历阳光窗口 + 计划筛选 + 分享卡片 | 月历 + 异常日标记（昼/夜/无/缺）+ CSV/PNG 导出 | 无分享卡片；导出按钮与原稿位置不同 | 补分享卡片（图片导出已具备） |
| **S09 compare 时间比较** | 多日期方位/高度对照 + 同日曲线 | 多日期对照 + 曲线 | 无「同一天多时段」视图 | 增加单日分时视图 |
| **S10 settings 设置** | 坐标系/时区/定位授权/角度单位/隐私/说明 | 阈值、主题、权限、备份 | 缺角度单位、隐私说明的正式入口 | 补分区与小标题 |
| **Index 壳** | 原稿无（桌面布局） | 5 Tab + 顶部 TopBar | 底部 Tab 与「更多」聚合的逻辑原稿未定义 | 需补导航设计文档 |
| **PlaceDetailPage** | 原稿无 | 机位详情/编辑/删除 | **无设计依据** | 按 locations 卡片语言派生 |
| **PlanDetailPage** | 原稿无 | 计划详情 | **无设计依据** | 按 planner 卡片语言派生 |

## 3. 需保留的优秀实现

1. 首页信息层级（eyebrow → 标题 → 副标题 → hero → 数据卡）与原稿一致；
2. KPI 三列 + 曲线卡的自适应换行在真机上无截断；
3. 反向寻光的**窗口语义**（起止/时长/单点命中/不足 1 分钟）比原稿更完整；
4. 日历的异常日文字+颜色双通道标记（昼/夜/无/缺）优于原稿；
5. 相机/传感器权限与降级路径（手动经纬度）符合原稿要求。

## 4. 需彻底重设计

1. **主题基线**：确认产品是「浅色为主 + 深色可选」还是原稿松色为主，并建立双主题 token；
2. **导航与多设备布局**（见 `UI0_RESPONSIVE_MATRIX.md`）；
3. **图表视觉语言**（sunpath 准星画布、compare 分时视图、reverse 结果卡）；
4. **动效规范**（见 `UI0_MOTION_SPEC.md`）；
5. **详情页**（Place/Plan Detail）缺设计依据，需补。
